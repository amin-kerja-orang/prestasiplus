## 0. Read first (findings that change how to read the tables)

1. **Placeholder items are not visible.** The brief assumed unbuilt Pentadbiran items render "Belum tersedia". In code they do not: `menu.ts:219-222` renders built items only (a group with none is dropped), and `core-routes.ts:174-175` redirects `/admin/p/:itemId` to `/admin/command-center`. So every unbuilt KS-/BS- item is **"Not in menu"** and the walker will not see a "Belum tersedia" page for it. (The "Belum tersedia dalam prototaip" page, `prototype-scope.ts:55`, is a different thing: routes outside the prototype role scope.) Count of "Placeholder" is therefore 0.
2. **Menu ids vs the v2 doc.** V2 doc §6 puts the paper list at KS-06, the builder at KS-09, Kontrak at KS-08, Tanda Karangan at KS-10. In code only **KS-09 "Pembina Kertas" (`/admin/spm/kertas`)** is built; it carries both the list and the builder. KS-06, KS-08, KS-10, KS-12 have no route (`menu.ts:118,120,122,124`).
3. **`/admin/questions` (BS-01) is the legacy .my question store (M04), not the canonical exam tree.** The Bijak SPM bank is `/admin/spm/soalan` (KS-02 "Bank Soalan SPM", label per `menu.ts:114`). Old A3/P6 are compared with KS-02.
4. **Prototype data is mock.** Papers, batches and blueprints are seed data (`server/admin.ts:149-196`, `data/registry.ts:182`). Seeded record ids to pick: draft paper `kp-seed-1`, intake batch `ek-demo-1`, curated student papers `mat-k1-2025-a`, `mat-k2-2025-a`, `sn-k2-2025-a`, `sej-k2-2025-a` (`data/registry.ts:55-170`).
5. **Host of the Blade `/admin/**` screens is not stated in DISC** (only the Panel host `admin.prestasiplus.cloud` is). Blade host below is written `prestasiplus.cloud` and is UNVERIFIED.
