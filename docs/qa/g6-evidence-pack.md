### 3.3 Re-check of the documented failure allowance

The allowance quoted in reviews is **"be:verify green apart from the 5 known local failures and 1 intermittent `test/games/solo/solo.spec.ts`"** (`docs/ops/go-live-bijak-spm.md` lines 134 and 337), with the five named in `docs/plan/half-am/LEAD-PROMPT.md` line 53: **4 in `migrate-cli.spec.ts`** and **1 in `pg-source.spec.ts`** ("a failed connection reports no password and no user"). `docs/qa/full-testing-25oct.md` R-8 repeats it: "Local `be:*` needs the stub schema engine and the PostgreSQL on port 55432; 5 known failures ... any new failure is real".

**Verdict: the allowance still holds exactly, and it is an environment artifact, not a defect.**

- **Local, on `9924a2f6`: 5 failures in 2 files - the same 5, in the same two files.** `test/db/migrate-cli.spec.ts` x 4 ("migrate applies every migration", "migrate is repeatable", "seed runs against the migrated database", "reset refuses to run when NODE_ENV=production") and `test/migration/anonymise/pg-source.spec.ts` x 1 ("a failed connection reports no password and no user"). No sixth failure appeared.
- **Cause confirmed.** The four `migrate-cli` failures all trace to `Error: Schema engine error:` - the offline stub refuses, so no migration is applied and the follow-on assertions fall over (`The table public.schools does not exist`, `relation "_prisma_migrations" does not exist`). The `pg-source` one expects a connection failure that a trust-auth loopback cluster does not produce. Both are properties of the local setup the allowance itself prescribes.
- **CI on the same sha has zero failures** (section 3.1: 8097 passed, 12 skipped, 0 failed). So nothing is hiding behind the allowance: the five are local-only, and the rule "any new failure is real" (`full-testing-25oct.md` R-8) is still a safe rule to apply.
- **The intermittent `test/games/solo/solo.spec.ts` did not fire** in either the CI run or this local run. One clean pass each is not proof the flake is gone; AZ-25 on #113 is still open and the test should keep its watch.
- One cosmetic difference from CI: **13 skipped locally against 12 in CI** (total 8109 in both). One extra environment-gated skip locally; it does not change the totals.

**So the sentence reviewers quote is still accurate at `9924a2f6`.** It was last re-checked here on 24 Oct 19:20 UTC, after the #256 / #261 / #282 / #293 merges of that evening.
