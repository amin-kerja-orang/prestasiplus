Tarikh: 2026-11-03. Sumber kebenaran: `docs\Matriks-Akses-Peranan .xlsx` (disahkan melalui `docs\ROLES-MATRIX-LINES.md` dan `src\app\prototype-scope.ts` TEACHER_ITEMS / SCHOOL_ADMIN_ITEMS).

## 0. Kaedah dan had (baca dahulu)

- V1 (prestasiplus.my): tiada log masuk guru / admin sekolah. Bahan = dokumen discovery (M10, M11, M12, M08, M26, M27-admin-sekolah-screens, L06, L07, R10, M01) dan skrin sidebar pengguna. Banyak skrin Admin Sekolah 1.0 ditanda NOT FOUND dalam dokumen V1 (kandungan tidak pernah diperhatikan: DSKP Heatmap, Laporan Bulanan, Statistik Penggunaan versi sekolah, Senarai Pelajar/Guru/Kelas). Untuk baris ini "V1" bermaksud "hanya nama menu + analog".
- V2 (prestasiplus.cloud): hanya kod salinan `prestasiplus-reference\backend`. Admin sekolah di V2 tiada portal sendiri: ia memakai portal `/admin` (layout admin, skop ikut sekolah) dan portal guru memakai `resources\views\guru\*`. Tiada paparan V2 `/admin-sekolah/*` (disahkan: M27 doc 0.2).
- V3: dua-tiga sumber sahaja kerana lorong pelayar 3 diminta dilepaskan oleh penyelaras di pertengahan kerja. Digunakan: (a) tangkapan skrin `ram-audit\*.png` (dilihat sendiri untuk Admin Sekolah; Guru melalui `ram.json`), (b) satu pas teks DOM Guru yang sempat dijalankan pada 2026-11-03 (20 laluan Guru, sebelum lorong dilepaskan), (c) kod V3 di `src`. Skrin Admin Sekolah tidak diuji semula secara hidup: butang/tindakan tidak diklik; ia dinilai daripada tangkapan skrin + kod. Perkara yang tidak disahkan ditanda "(belum disahkan)".
- Tiada fail repo diedit. Tiada pelayan/ujian dijalankan.
- Awalan bukti: `SS` = `.evidence/ (lokal, tidak dalam repo) screenshots/v3-github/`. Kod V3 = `src\...`.
