# Field and behaviour register - Murid portal (R1)

Scope: every input, control, validation, error, state, state machine, calculation and dialog of `docs/prd/r1/10-murid.md` plus the shared inputs (login, registration, reset, profile, settings, ticket, report dialog, question-answering controls) that `40-cross-cutting.md` and the code define. READ-ONLY audit; no repo file was changed.

Evidence tags: S = SRS text (10-murid.md section/FR), X = 40-cross-cutting, V2 = capture in `.evidence/v2-screens/murid*`, C = `packages/contract/src/<file>`, F = front-end `src/**`, M = 60-api-contract / 50-data-model-erd.
Status values: COMPLETE (a developer can build it from the SRS as written), PARTIAL (some parts specified), MISSING (specified nowhere in the SRS; code or V2 gives a source, quoted in the proposal), MISSING-NO-SOURCE (no source; proposal is [PROPOSED]).
"Proposed spec" is written to be pasted into the PRD as is. Labels in quotes are exact BM. Where I could not find a source the text is marked [PROPOSED] and needs the user's copy approval (D94).

Legend for API/DM names: API-xxx-nn are rows of 60-api-contract.md; DM-nn / table names are from 50-data-model-erd.md. "[PROPOSED extension]" = a new field or code on an existing API row.

### 2.6 Marking rules per answer type (e) - consistent with `packages/exam-core/src/grading.ts` and `math-expr.ts`

Common to all: grading is on the server only; the key never reaches the page before Semak/Hantar. A leaf has `marks` (integer >= 0); `awarded` is an integer 0..marks. Part status: `betul` awarded = marks; `separa` 0 < awarded < marks; `salah` awarded 0 with an answer; `kosong` blank (no choice, no text, no steps, no photo); `belum_dimarkah` waits for the pupil ("Belum dimarkah — perlu semakan"). The system NEVER turns an unreadable or low-confidence answer into a silent 0. Question awarded = sum of its leaf parts; section = sum of counted questions (choose-N: best N by marks, tie = lower position; the others get `counted:false`); score = sum of sections. Pupil-visible percent = round half up(score / max x 100). One `practice_answers` row per leaf part with `marks_awarded`/`marks_max`; "correct" in every report only when awarded = marks. Rewards: Syiling rate x awarded marks (Bijak) or x correct units (drills) and 10 XP each.
