### 4.4 Expected behaviour that looks like a bug: 429 on the admin question list

On `r1/admin-list-perf` (in base since BASE-137, `dac398fa`, @ 69f465c8) the admin question list `GET /api/questions` is limited **per user**: **240 calls a minute** (60 before REQ-B-061, which raised it because normal use reached 60); above that the answer is 429 `RATE_LIMITED` with a `Retry-After` header (`apps/api/src/modules/questions/http/admin.controller.ts:24-35` at BASE-146; spec `test/questions/list-rate-limit.spec.ts`).
