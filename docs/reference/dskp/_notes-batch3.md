# DSKP extraction notes - batch 3

Source PDFs (read-only, not copied): `D:\prestasiplus\` - Pendidikan Moral.pdf, Pend Seni Visual T4 n T5.pdf, Landskap dan Nurser.pdf, DSKP KSSM subjek vokasional Katering dan Penyajian.pdf.
All four are KSSM DSKP "Terbitan 2018, Bahagian Pembangunan Kurikulum KPM, September 2018" (Tingkatan 4 dan 5). All have a text layer (no OCR needed). Text extracted with `pdftotext` (layout + raw modes), SK/SP numbering and wording kept as printed (including printed typos).

Common to all four: the Catatan column (Cadangan Aktiviti / Nota / Cadangan nilai / isu) is intentionally NOT extracted (not curriculum standards). No subject code is printed on any cover, so `subjectCode` is `null`. None of the four DSKP states a written-exam (SPM) paper format; assessment described is school-based (PBD) with Tahap Penguasaan 1-6.

General Tahap Penguasaan scale (identical in all four DSKP, Jadual "Pernyataan Tahap Penguasaan Umum"): 1 Tahu; 2 Tahu dan faham; 3 Tahu, faham dan boleh buat; 4 ... dengan beradab; 5 ... beradab terpuji; 6 ... beradab mithali. Moral differs slightly: its "Tahap Penguasaan Keseluruhan" table maps 1-2 mengetahui/mengenal pasti, 3-4 memahami/memberi maklum balas, 5-6 mengaplikasi/menilai, etc. (Jadual 5 in the PDF).

## 1. Pendidikan Moral (`pendidikan-moral.json`)

- Hierarchy: Bidang > Standard Kandungan (topic, x.y) > Standard Pembelajaran (x.y.1-6). The whole KSSM Moral has 7 bidang (1-4 are T1-T3); this DSKP covers Bidang 5 Insan Bermoral, 6 Jati Diri Moral, 7 Moral dan Kenegaraan for BOTH forms, with different topics per form but the SAME codes (e.g. 5.1 exists in T4 "Norma Masyarakat" and T5 "Norma Masyarakat Global"). Always key by (level, code).
- JSON unit = one SK (because each SK has its own Standard Prestasi table): 24 units (T4 12, T5 12), 24 SK (T4 12: 5.1-5.4, 6.1-6.3, 7.1-7.5; T5 12 same code ranges), 144 SP (72 + 72, always exactly 6 per SK), TP present: yes, 6 Tahap Penguasaan descriptors per SK = 144 (all aligned 1-6, verified by sentence count).
- SP pattern per SK: x.y.1-4 cognitive (define/list -> explain -> evaluate/predict/analyse), x.y.5 "Mengekspresikan perasaan ..." (affective), x.y.6 "Mengamalkan ..." (practice in daily life). TP pattern: 1 Menyatakan, 2 Menerangkan, 3 Menilai, 4 Menganalisis, 5 Menghayati dan mempamerkan, 6 Menghayati dan mengamalkan ... secara tekal serta boleh dicontohi.
- Cognitive/KBAT: DSKP has a KBAT section (Jadual: Mengaplikasi, Menganalisis, Menilai, Mencipta) and a PBD section; SP/TP verbs do not carry explicit cognitive levels, but TP 1-4 map approximately to remember/understand/evaluate/analyse. DSKP says assessment "lebih menekankan kepada usaha ke arah penambahbaikan serta perkembangan dan bukan pencapaian kognitif semata-mata" (domains: penaakulan moral, emosi moral, perlakuan moral). Minimum 64 hours over T4+T5. 18 universal values referenced in Catatan only.
- Written-exam relevance: GOOD for knowledge/reasoning items (SP x.y.1-4, TP 1-4) - tag questions by (level, SK code) and optionally SP code. SP x.y.5 (feelings) and x.y.6 (practice) and TP 5-6 are attitude/behaviour and are not testable by a written question. No assessment format given in the PDF.
- Fidelity notes: printed typo kept - T4 SP 7.2.5 has capital "Berbeza". T5 SP 7.1.6 was reconstructed from interleaved columns (text confirmed against the layout dump). Stream of TP sentences was column-extracted and validated (144 sentences = 24 SK x 6).
- Comparison with `D:\Dev Projects\prestasiplus-reference\backend\tools\import\dskp\dskp-curriculum.json` (subject "Pendidikan Moral", sid 7): file has 72 rows = T5 only, codes 5.1.1-7.5.6, strands Insan Bermoral 24 / Jati Diri Moral 18 / Moral dan Kenegaraan 30. Gaps: (a) no T4 at all (72 SP missing); (b) no SK titles/levels/themes, no TP descriptors; (c) 3 wording differences vs the PDF: T5 5.4.1 (".cloud" adds "mengekalkan" - PDF: "...yang sahih demi kesejahteraan sejagat."), T5 7.1.6 (".cloud" "bersama" - PDF "bersama-sama"), T5 7.4.5 (".cloud" omits "apabila" - PDF: "Mengekspresikan perasaan apabila mengharumkan nama negara di persada dunia."). The other 69 T5 rows match exactly. Note T4 and T5 reuse the same codes, so a (code-only) key in `.cloud` collides if T4 is added.

## 2. Pendidikan Seni Visual (`pendidikan-seni-visual.json`)

- Hierarchy: Bidang (Sejarah dan Apresiasi Seni Visual, Seni Halus, Reka Bentuk, Seni Kraf, Komunikasi Visual) > Tajuk (topic, numbered n.0 within each form) > four fixed Standard Kandungan per topic: n.1 Persepsi Seni, n.2 Eksplorasi Seni, n.3 Ekspresi Seni, n.4 Apresiasi Seni > SP (n.m.k). One Standard Prestasi (TP 1-6) table and one "Objektif" list per topic. JSON unit = one Tajuk (keeps bidang, tajuk, hoursMin, objektif).
- Counts: T4 9 topics / 36 SK / 65 SP; T5 8 topics / 32 SK / 56 SP; total 17 units / 68 SK / 121 SP; TP 6 per topic = 102 (aligned 1-6). Minimum hours: T4 64, T5 54. T4 topics: Alat Kebesaran dan Perhiasan Diraja; Seni Lukisan; Seni Catan; Seni Cetakan; Reka Bentuk Landskap; Reka Bentuk Hiasan Dalaman; Seni Ukiran; Seni Reka Grafik (Ilustrasi); Seni Foto (Genre Fotografi). T5 topics: Seni Bina; Seni Lukisan; Seni Catan; Seni Arca; Reka Bentuk Industri; Seni Batik; Seni Reka Grafik (Infografik); Seni Foto (Manipulasi Imej dan e-Portfolio).
- Cognitive/KBAT: DSKP has KBAT (4 levels used: mengaplikasi, menganalisis, menilai, mencipta; inquiry-based learning). Overall TP descriptors (Jadual 4) go knowledge -> explain -> apply -> analyse -> express creatively -> create + appreciate using "Bahasa Seni Visual" and "Pemikiran Seni Visual".
- Written-exam relevance: PARTIAL / PRACTICAL-ORIENTED (flag). The subject is art-making (model, karya, portfolio, pameran). Only the n.1 Persepsi Seni (history, definitions, types, tools, concepts: TP 1-2) and n.4 Apresiasi Seni (describe/explain artworks using Bahasa Seni Visual) are plausible for written MCQ/short-answer tagging; n.2 Eksplorasi and n.3 Ekspresi (TP 3-6) are production tasks. The PDF has a Glosari (T4 and T5, pp.104-114) that is not extracted.
- Fidelity notes: printed numbering gaps kept - T5 Seni Bina SK 1.2 has only SP 1.2.2 (no 1.2.1) and T5 Seni Lukisan SK 2.1 has only SP 2.1.2 (no 2.1.1). T4 Seni Reka Grafik SK 8.1/8.4 titles are split across columns in the PDF and were reassembled; SP 8.3.1 includes sub-items (i)/(ii). T5 topic 5-6 have 5 objectives, others 4. Objectives were taken from the layout text.
- Comparison with `dskp-curriculum.json` (subject "Pendidikan Seni Visual", sid 13): 37 rows, T5 only, 8 strands = the 8 T5 topics. Gaps: (a) T4 absent entirely (65 SP missing, 9 topics); (b) of the 56 T5 SP in the PDF, only 35 match exactly and 2 more differ only in a trailing full stop (T5 6.2.1 and 7.2.1; the PDF prints them without/with a period inconsistently), so 19 T5 SP are missing in `.cloud` (T5: 1.2.2, 1.4.3, 2.1.2, 2.2.1, 2.3.1, 2.4.3, 3.1.1, 3.2.1, 4.3.1, 4.4.2, 5.1.1, 6.1.1, 6.1.2, 6.1.3, 6.1.5, 8.1.2, 8.1.3, 8.2.1, 7.4.2 - topic-prefixed codes are topic.SK.SP); (c) no SK (Persepsi/Eksplorasi/Ekspresi/Apresiasi) layer, no TP, no hours/objectives. Codes repeat across topics (1.1.1 exists in every topic), so `.cloud` rows must be keyed by strand + code.

## 3. Landskap dan Nurseri (`landskap-dan-nurseri.json`) - vocational MPV

- Hierarchy: Modul (unit, 1.0-7.0; Modul 1-4 = T4, 5-7 = T5) > Standard Kandungan (x.y) > Standard Pembelajaran (x.y.z). Standard Prestasi (TP 1-6) is per MODULE, not per SK. Minimum 256 h/year. T4 modules: 1.0 Pengenalan kepada Landskap dan Nurseri (29 h), 2.0 Pembiakan Tumbuhan (59 h), 3.0 Penanaman dan Penyenggaraan Tanaman di Nurseri (40 h), 4.0 Reka Bentuk Landskap (128 h). T5: 5.0 Pelaksanaan Aktiviti Pelandskapan (144 h), 6.0 Pengurusan Kawasan Landskap (64 h), 7.0 Keusahawanan (48 h).
- Counts: T4 4 modules / 9 SK / 72 SP; T5 3 modules / 10 SK / 68 SP; total 7 / 19 / 140. TP: yes, but for modules 1.0, 3.0, 4.0 and 7.0 (TP 1-4) the PDF prints the TP statements as one merged list across TAHAP cells; per-level alignment is not recoverable from the text layer, so those are stored as a single entry with `tp: null` (or `"1-4"` for module 7.0) and a `note`. Modules 2.0, 5.0, 6.0 are aligned 1-6 (module 5.0 TP3/TP4 boundary for "Merekod bahan ..." is approximate).
- Competency / practical based (psychomotor: grafik drawing, propagation, planting, construction, maintenance; entrepreneurship). Assessment = Pentaksiran Berasaskan Standard + Pentaksiran Berasaskan Projek (folio, model, kertas cadangan; KBAT via projects). Cognitive/KBAT: general only (KBAT section; TP verbs: menyatakan/menyenaraikan -> menerangkan -> melaksanakan -> mencadangkan -> menghasilkan secara kreatif).
- Written-exam relevance: PRACTICAL-ONLY subject (flag). Only the knowledge-type SP (menyatakan/menyenaraikan/menerangkan/menjelaskan, e.g. 1.1.x, 1.2.x, 2.x ... knowledge items, 7.x business terms) are possible for tagging; production/skill SP (melaksanakan, menghasilkan, melukis, membina) are not testable on paper. No written paper format is stated in the DSKP. Recommend treating as low priority / practical-only in the question bank.
- Fidelity notes: printed numbering quirks kept - SK 1.3 (Amalan Keselamatan) has SP numbered 1.4.1-1.4.5; SK 7.2 (Rancangan Perniagaan) has SP numbered 7.3.1-7.3.9; SP 1.4.4 is printed truncated ("...kemalangan dan"). The panel list is not extracted (personal names).
- Comparison with `dskp-curriculum.json`: subject NOT present (no "Landskap dan Nurseri" rows) - full gap (7 modules / 19 SK / 140 SP / TP).

## 4. Katering dan Penyajian (`katering-dan-penyajian.json`) - vocational MPV

- Hierarchy: Modul (unit, 1.0-8.0; Modul 1-4 = T4, 5-8 = T5) > SK (x.y) > SP (x.y.z). TP (1-6) is per MODULE, except Modul 1.0 which has two TP tables (one for SK 1.1, one for SK 1.2-1.3; stored with `appliesToSK`). Minimum 256 h/year each form. T4: 1.0 Pengenalan Bidang Perkhidmatan Makanan (16 h), 2.0 Peralatan dan Bahan dalam Perkhidmatan Makanan (16 h), 3.0 Pengenalan kepada Perkhidmatan Penyajian (32 h), 4.0 Hidangan Asas (192 h). T5: 5.0 Menu dalam Perkhidmatan Makanan (20 h), 6.0 Hidangan Set Menu (92 h), 7.0 Hidangan Lengkap dan Seimbang (112 h), 8.0 Keusahawanan dalam Katering dan Penyajian (32 h).
- Counts: T4 4 modules / 18 SK / 140 SP; T5 4 modules / 13 SK / 100 SP; total 8 / 31 / 240. TP present: yes (aligned 1-6 for every table; module 2.0 TP4 boundary for three statements is approximate and noted in the JSON).
- Competency / practical based (amali: mise en place, recipe production, table setting, service); pattern for food modules: define -> plan menu -> standard recipe -> mise en place -> produce -> evaluate -> add value -> create new recipe. Assessment = Pentaksiran Berasaskan Standard + Pentaksiran Berasaskan Projek (KBAT via projects). Cognitive/KBAT: general only.
- Written-exam relevance: PRACTICAL-ONLY subject (flag); only knowledge SP (e.g. 1.1.x definitions/segments, 1.2.x/1.3.x safety and environment, 2.x classification of equipment/ingredients, 3.x service types/linen, 5.1.x menu, 8.x entrepreneurship/cost) are plausible for written tagging; "Menghasilkan ... hidangan/resipi" SP are practical. No written paper format stated.
- Fidelity notes: printed typos kept ("peranggu", "resepi", "pralatan", "Pekhidmatan" in a heading). SP 3.3.6 is printed "3.3,6" (comma) and normalised to 3.3.6. Roman sub-items (i, ii, ...) are inlined in SP text. Panel list not extracted.
- Comparison with `dskp-curriculum.json`: subject NOT present - full gap (8 modules / 31 SK / 240 SP / TP).

## Cross-cutting findings for the question-bank design (D9 / TRACKER D40(e))

- Three different hierarchies appear in this batch: Moral = Bidang > SK(topic) > 6 SP, TP per SK; PSV = Bidang > Tajuk > fixed 4 SK(Persepsi/Eksplorasi/Ekspresi/Apresiasi) > SP, TP per Tajuk; MPV (Landskap, Katering) = Modul > SK > SP, TP per Modul. A uniform tag target of (subject, level, unit code, SK code, optional SP code) works for all, provided `unit.code` is scoped by level (codes repeat between T4 and T5 in Moral and PSV).
- `.cloud` file only knows `subject / strand / code / sp` and covers T5 only for Moral and PSV; it cannot represent T4, SK titles, TP, hours or objectives.
- Practical-only subjects to flag for the question bank: Landskap dan Nurseri, Katering dan Penyajian (and, partially, Pendidikan Seni Visual).
