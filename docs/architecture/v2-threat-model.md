## How to read this

- Paths starting `src/` or `test/` are relative to `apps/api/`. Other paths (`.github/`, `deploy/`, `functions/`, `scripts/`, `docker/`, `docs/`) are relative to the repository root.
- `Control (file:line)` was read in the code on the base above. `Test (file › test name)` names a test that exists; each name was checked by grep against the spec file (describe / it titles; `%s` marks a templated `it.each` title).
- Status values: **Pass** = control exists and an existing test is named. **Partial** = control exists, no test (or the test covers only part of the risk). **Gap** = control missing, or only a known limitation. **Draft** = the control and test live in a branch that is not merged in this base: *draft, sahkan selepas BE-36/BE-38 merge*.
- Draft rows (BE-36 AI extraction, PR #86, head `origin/be/BE-36-ai-extraction`; BE-38 intake workflow, PR #85, head `origin/be/BE-38-intake-workflow`) were read with `git show origin/<branch>:<path>`. Their `src/` paths and line numbers are those of that branch tip, not of this base.
- No real personal data is used in this file. Items that could not be confirmed from code are marked "Perlu pengesahan".
